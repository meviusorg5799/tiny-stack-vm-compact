# tiny-stack-vm-compact

A tiny stack VM for make.fun's tiny-stack-vm-01-run-20261122: the full ISA in one small file — 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exit codes.
